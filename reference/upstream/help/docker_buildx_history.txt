Usage:  docker buildx history [OPTIONS] COMMAND

Commands to work on build records

Options:
      --builder string   Override the configured builder instance
  -D, --debug            Enable debug logging

Management Commands:
  inspect     Inspect a build record

Commands:
  export      Export build records into Docker Desktop bundle
  import      Import build records into Docker Desktop
  logs        Print the logs of a build record
  ls          List build records
  open        Open a build record in Docker Desktop
  rm          Remove build records
  trace       Show the OpenTelemetry trace of a build record

Run 'docker buildx history COMMAND --help' for more information on a command.
