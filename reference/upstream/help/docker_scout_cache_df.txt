 Show Docker Scout disk usage

Usage
  docker scout cache df

Description
Show temporary or cached data used by Docker Scout

Temporary data are where image is temporarily stored while generating the SBOM.
These date are usually deleted at the end of the generation, but in case the process has been
killed some data might still be there.

Once generated, SBOMs are cached locally so they are not generated or fetched again. These cached
SBOMs are used by Scout when you want to display data for an image.
