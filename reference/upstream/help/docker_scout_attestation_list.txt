 List attestations for image

Usage
  docker scout attestation list OPTIONS IMAGE

Aliases
  list, ls

Description
The docker scout attestation list command lists attestations for images.



Flags
      --format string           Output format:
                                - list: list of attestations of the image
                                - json: json representation of the attestation list (default "json") (default "list")
      --org string              Namespace of the Docker organization
  -o, --output string           Write the report to a file
      --platform string         Platform of image to analyze
      --predicate-type string   Predicate-type for attestations
      --ref string              Reference to use if the provided tarball contains multiple references.
                                Can only be used with archive
