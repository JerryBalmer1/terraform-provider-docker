Docker Pass CLI - Manage your local secrets.

Usage: docker pass rm name1 name2 ...

Flags:
      --all   Remove all secrets


Examples:
### Remove a specific secret:

```console
$ docker pass rm GH_TOKEN
```

### Remove multiple secrets:

```console
$ docker pass rm GH_TOKEN NPM_TOKEN
```

### Remove all secrets:

```console
$ docker pass rm --all
```
