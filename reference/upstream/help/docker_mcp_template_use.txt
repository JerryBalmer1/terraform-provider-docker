Docker MCP Toolkit's CLI - Manage your MCP servers and clients.

Usage: docker mcp template use <template-id>

Flags:
      --connect stringArray   Clients to connect to (can be specified multiple times). Supported clients: [claude-code claude-desktop cline codex continue crush cursor gemini goose gordon kiro lmstudio opencode sema4 vscode zed]
      --name string           Override the profile name (defaults to template title)


Examples:
  # Create a profile from the ai-coding template
  docker mcp template use ai-coding

  # Override the profile name
  docker mcp template use ai-coding --name "My AI Tools"

  # Create and connect to a client in one shot
  docker mcp template use ai-coding --connect cursor
