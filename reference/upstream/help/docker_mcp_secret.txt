Docker MCP Toolkit's CLI - Manage your MCP servers and clients.

Usage: docker mcp secret

Available Commands:
  ls          List all secrets from the local OS Keychain as well as any active Secrets Engine provider
  rm          Remove secrets from the local OS Keychain
  set         Set a secret in the local OS Keychain


Examples:
### Pass the secret via STDIN

> echo my-secret-password > pwd.txt
> cat pwd.txt | docker mcp secret set POSTGRES_PASSWORD
